Colour describes the selected reading. Implied notes are named in the explanation; they are never added to the notation. On a narrow screen, scroll the score sideways.

Load files or an analysis URL

When hosted, this viewer loads Tempest.json beside the HTML. Its defaultScore names the MEI; relative paths are resolved against the JSON’s URL. A remote host must allow cross-origin requests (CORS).

For local files, choose the JSON and MEI together using Load files, or select them one after the other. Automatic loading works when the folder is served over HTTP. From that folder, run:

python3 -m http.server 8000 --bind 127.0.0.1

Then open http://127.0.0.1:8000/Tempest.html.

Edit musical notation in the MEI and edit questions, note targets, navigation and labels in the JSON. Reload to see changes. Internet access is needed for Verovio 6.3.0. No older score or analysis is silently substituted if loading fails.
